# 롤 성향 진단 (LoL Personality Test)

10개의 질문으로 알아보는 나의 롤 성향. 탑·정글·미드·원딜·서폿 중
내 기질에 맞는 라인과 추천 챔피언을 찾아주는 웹 진단 콘텐츠입니다.

## 구조

```
index.html        시작 화면
quiz.html         10문항 진단 (진행바 · 실시간 채점)
result.html       결과 화면 (레이더 차트 · 성향 분석 · 챔피언 추천)
assets/
  styles.css      공용 스타일 (헥스텍 골드 + 협곡 딥블루 테마)
  img/            포지션 캐릭터 이미지 (top/jungle/mid/adc/support)
```

## 동작 방식

1. `quiz.html`에서 10문항에 답하면 5개 포지션에 점수가 매겨집니다.
2. 점수는 `sessionStorage`에 저장되어 `result.html`로 전달됩니다.
3. 1·2위 성향 조합으로 플레이스타일과 추천 챔피언을 보여줍니다.

## 리뉴얼 노트

- 순수 HTML/CSS/JS, 별도 빌드 과정 없이 정적 호스팅(Netlify 등)에 바로 배포 가능.
- 채점 로직·성향 설명·챔피언 데이터는 기존 콘텐츠를 유지했습니다.
- 디자인을 롤 클라이언트 감성(골드+딥블루)으로 개편하고 모바일 대응을 추가했습니다.
- Chart.js(레이더 차트)는 CDN 로드 실패 시에도 나머지 결과가 정상 표시되도록 방어 처리했습니다.

## 알려진 개선 여지

- `assets/img/` 이미지가 장당 2MB 내외입니다. WebP 변환 또는 512px 리사이즈로 로딩 속도를 크게 줄일 수 있습니다.
